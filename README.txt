# Ruth Ardenio Portfolio — Version 1

This is the first working version of Ruth's personal portfolio.

## Files

- index.html — Home page
- css/style.css — All visual styling
- js/main.js — Animations, mobile navigation, active section
- images/profile/ — Put your photos here
- Ruth_Ardenio_CV.pdf — Put your CV here

## Open in VS Code

1. Extract the project folder.
2. Open the `ruth-portfolio` folder in Visual Studio Code.
3. Put your CV PDF in the root folder and name it:
   `Ruth_Ardenio_CV.pdf`
4. Put your chosen portrait inside:
   `images/profile/`
5. In `index.html`, replace the `photo-placeholder` div with an `<img>` tag when you are ready.

## Preview

The simplest option is to install the VS Code extension:
"Live Server"

Then right-click `index.html` and choose:
"Open with Live Server"

You can also open `index.html` directly in a browser, although Live Server is more convenient while editing.
